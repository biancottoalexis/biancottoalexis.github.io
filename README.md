
# Portfolio - Alexis Biancotto

## Présentation

Ce portfolio a été réalisé dans le cadre de ma formation
en Bachelor Informatique - Cybersécurité à Ynov Campus
Aix-en-Provence.

Il permet de présenter mon parcours, mes compétences,
mes expériences et mes projets informatiques.

## Technologies utilisées

- HTML
- CSS
- Visual Studio Code
- GitHub

## Pages du site

- Accueil : présentation, parcours et compétences
- Mes projets : liste des réalisations
- Kombaly : présentation de la plateforme
- RED : présentation du jeu en Go
- Contact : email, GitHub, LinkedIn et CV

## Mes projets

### Kombaly

Plateforme de gestion pour les clubs de sports de combat.

Projet personnel développé seul, de sa conception
jusqu'à sa publication.

Technologies : HTML, CSS, JavaScript,
bases de données et OVH.

Site : https://kombaly.fr/

### RED

Jeu de rôle développé en Go, jouable en ligne de commande.

Projet réalisé en binôme à Ynov Campus.

Fonctionnalités :
- Combat au tour par tour
- Économie
- Progression du personnage
- Narration avec plusieurs choix

## Installation

1. Télécharger le projet depuis GitHub.
2. Ouvrir le dossier dans Visual Studio Code.
3. Ouvrir le fichier index.html.
4. Lancer Live Server ou ouvrir index.html dans un navigateur.

## Responsive

Le site est adapté aux ordinateurs et aux téléphones
grâce à CSS et aux media queries.
